# Student Grade Calculator - C Programming

A simple C program that calculates a student's average and grade.

## What it does
- Asks for student name
- Asks for Maths, English, Kiswahili marks
- Calculates average
- Shows Grade A, B, C or Fail

## How to run
1. Open in Code::Blocks / Dev-C++
2. Compile main.c
3. Run and enter marks
